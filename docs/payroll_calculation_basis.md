# ฐานการคำนวณเงินเดือนแบบตรวจทานได้

อ้างอิง ณ วันที่ 19 สิงหาคม 2569 ฟีเจอร์นี้ออกแบบเป็นเครื่องมือจัดทำร่างเงินเดือนภายในร้าน ไม่ใช่ระบบยื่นแบบ ภ.ง.ด.1 หรือระบบนำส่งเงินสมทบประกันสังคมอัตโนมัติ ผู้จัดการร้านต้องตรวจยอดก่อนอนุมัติหรือจ่ายเงินจริง

| รายการ | ค่าเริ่มต้นในระบบ | ที่มา / หมายเหตุ |
|---|---:|---|
| ค่าใช้จ่ายเงินเดือน | 50% ของเงินได้จากการจ้าง แต่ไม่เกิน 100,000 บาทต่อปี | กรมสรรพากร: [การหักค่าใช้จ่าย](https://www.rd.go.th/556.html) |
| ค่าลดหย่อนส่วนตัว | 60,000 บาทต่อปี | กรมสรรพากร: [ตารางการหักลดหย่อน](https://www.rd.go.th/59674.html) — ผู้ใช้แก้ไขค่าอื่นของพนักงานได้ |
| ภาษีเงินได้ | ขั้นบันได 0%–35% | กรมสรรพากร: [อัตราภาษีเงินได้บุคคลธรรมดา](https://www.rd.go.th/english/6045.html) |
| เงินสมทบ ม.33 (ผู้ประกันตน) | 5% ของฐานค่าจ้างภายใต้เพดานที่ตั้งค่าได้ | ตรวจอัตราและเพดานตามประกาศสำนักงานประกันสังคมก่อนใช้งานแต่ละปี |

ระบบคำนวณภาษีด้วยวิธี **ประมาณการรายได้ของเดือนปัจจุบันเป็นรายปี** แล้วหารยอดภาษีประมาณการรายเดือนตามจำนวนรอบจ่าย พร้อมหักยอดภาษีที่คำนวณแล้วในเดือนเดียวกันเพื่อไม่ให้หักซ้ำในกรณีจ่ายวันที่ 7 และ 22 ผลลัพธ์และค่าตั้งต้นทั้งหมดแก้ไขได้ก่อนบันทึกรอบเงินเดือน

> กรมสรรพากรระบุว่าเงินล่วงเวลาและโบนัสต้องนำไปรวมประมวลผลภาษีในรอบนั้น และกรณีปรับเงินเดือนระหว่างปีควรปรับข้อมูลก่อนประมวลผลภาษีประจำเดือน ดู [คำถามที่พบบ่อยเรื่อง WHT](https://www.rd.go.th/62974/%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%87%E0%B8%B2%E0%B8%99%E0%B8%A0%E0%B8%B2%E0%B8%A9%E0%B8%B5%E0%B9%80%E0%B8%87%E0%B8%B4%E0%B8%99%E0%B9%84%E0%B8%94%E0%B9%89%E0%B8%AB%E0%B8%B1%E0%B8%81%E0%B8%A0%E0%B8%B2%E0%B8%A9%E0%B8%B5-%E0%B8%93-%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B8%88%E0%B9%88%E0%B8%B2%E0%B8%A2.html)
